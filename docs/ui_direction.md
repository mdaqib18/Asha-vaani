# Mobile App UI Direction (for Milestone 5+)

Recorded from user guidance and `SPEC.md §11`:

- **Quality bar:** UI must be simple, clean, and premium — no unnecessary clutter or generic filler ("no unnecessary slop").
- **Theme:** Use a cohesive, intentional, optimized color palette and clear structural hierarchy suited for field health workers.
- **SPEC §11 field ergonomics:**
  - Large touch targets (especially the push-to-talk mic button and confirm controls).
  - High contrast for outdoor daylight legibility on mid/low-end Android devices.
  - Minimal text per screen, icon-supported cues, and centralized i18n labels (English, Hindi, Kannada).
  - Clear status states ("Listening", "Processing", "Saved offline", synced/pending badges) and neutral clinical wording ("Suggest consulting ANM/doctor").
